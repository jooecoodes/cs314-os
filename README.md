# Unix System Calls & IPC Lab

A small set of C programs that demonstrate the core system-call patterns used for file I/O, process management, and inter-process communication on Linux.

Start here:

→ **[SETUP.md](SETUP.md)** — build instructions, dependencies, and how to run everything

Then work through the activities in order:

| # | Topic | Detailed walkthrough |
|---|-------|----------------------|
| 1 | File Operations | [FILE_OPERATIONS.md](FILE_OPERATIONS.md) |
| 2 | Process Management | [PROCESS_MANAGEMENT.md](PROCESS_MANAGEMENT.md) |
| 3 | Pipe-based IPC | [PIPE_IPC.md](PIPE_IPC.md) |
| 4 | Shared-Memory IPC | [SHARED_MEM_IPC.md](SHARED_MEM_IPC.md) |

Each activity is written snippet-by-snippet so you can follow the exact sequence of system calls and the reasoning behind them.
